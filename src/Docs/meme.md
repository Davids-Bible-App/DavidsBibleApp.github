## Meme Maker

### What it does

Design shareable scripture graphics directly inside the app. Choose a background, add text layers, style your verse, and export the finished image in PNG, WebP, or JPEG.

### Main controls

- **Upload BG**: add your own background images from local files.
- **From URL**: paste a web image link to use it as the canvas background.
- **BG Color ONLY**: switch to a pure color background instead of an image.
- **Image strip**: pick an existing background or delete unwanted uploads.
- **Flip / transform**: mirror the background horizontally or vertically.
- **Canvas format**: choose square, portrait, landscape, or original aspect ratios.

### Text editing

- **Add Text**: add a new movable text layer to the design.
- **Drag text**: click and drag a text layer to reposition it.
- **Layer list**: select, reorder, or delete layers from the sidebar.
- **Text style**: change font, size, color, stroke, shadow, wrap, and spacing.

### Templates and saving

- **Save as New Template**: store the current design so you can reuse it later.
- **Update Current Template**: keep the same template and save changes to it.
- **Apply Template**: tap a saved template thumbnail to restore that design.
- **Reset**: clear uploads and return to the preset background set.

### Export

- Select an export format and size from the menu.
- Tap **Export** to save the image to your device.
- Use higher export sizes for better quality when sharing.

### Notes

- Meme Maker auto-saves your work locally as you edit.
- Uploaded images are cached in the app folder and can be reused later.
- If a template uses an image, that image cannot be deleted until the template is removed.
